## 实验依据

- [MLJAR 与 TabularX 十数据集完整工具包对比](../docs/validation/README.md)：在八个分类任务和两个回归任务上运行两套工具，使用共同外部测试集，盘点预处理、模型选择、特征重要性、SHAP、学习曲线、混淆矩阵、公平性适用性、可信审计、持久化、报告和证据交付等实际工件。索引提供十数据集综合报告、逐数据集报告、结构化指标、工件清单与 [Notebook 文件夹](introduction/benchmarks/)。实验用于核对工件覆盖和报告边界，不作为严格等预算的性能排名。
- [证据交付实验验证索引](../docs/validation/evidence-delivery/README.md)：提供真实运行报告、结构化结果及故障恢复记录。各批次保留对应代码阶段与结论边界，不将历史实验混同为当前版本的重复验证。
