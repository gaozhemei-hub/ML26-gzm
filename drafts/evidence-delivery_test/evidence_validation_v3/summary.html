证据交付与局部恢复：扩展验证

本页展示你新增的“交付检查”和“失败后局部补做”。未合并队友的报告。

本轮结果：6/6 个组合通过全部检查。

覆盖三个公开数据集、两种模型，以及二分类、多分类和回归。每个组合仅进行一次小规模训练，再注入明确故障。

如何理解：训练、解释图和普通报告是原有能力；“发现应该交付但没有交付的内容，区分失败与不适用，并只补做失败部分”是本次新增能力。

这是人为故障注入实验，不是自然故障率统计；没有测量相对完整重跑的加速比。不证明预测性能、公平性或跨环境复现。

  • ✓ 原始表格重载预测一致：保存预处理器与模型，重载后直接接收原始测试表格；同时核对预测概率（如适用）
  • ✓ 持续失败不会误报完整：报告恢复成功不覆盖仍存在的解释失败
  • ✓ 真实解释及报告恢复：不再注入故障，实际执行 SHAP 和报告渲染
  • ✓ 解释文件删除后检出并补齐：删除本轮真实生成的一张解释图，再局部补做
  • ✓ 模型文件可由内存对象重新保存：模型没有重新训练；该恢复仍需要存活的 Python 会话
  • ✓ 恢复不调用模型训练：恢复阶段 fit 调用次数：0
  • ✓ 恢复前后预测一致：使用同一测试输入比较；不等于跨环境复现
  • ✓ 输入变化后拒绝沿用旧运行：在执行任何补做之前拒绝变化的上下文
