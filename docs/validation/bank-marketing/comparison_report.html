3. 解读

  • TabularX 最佳模型：lightgbm；MLJAR 最佳模型：NoneType。
  • 两者 ROC-AUC 几乎持平；MLJAR 以更多假阳性换取更少假阴性，因此 Balanced Accuracy 和 Macro-F1 更高。
  • TabularX：优点是把测试隔离、泄露/漂移审计、模型重载核验和交付状态纳入同一次运行；不足是本次未观察到 ALE，原生 WeasyPrint 导出在 Windows 缺少 GTK 时需由 Chrome 兼容导出 PDF。
  • MLJAR：优点是逐模型生成 Markdown 文档、学习曲线和特征重要性；不足是本次只有 Random Forest 观察到 SHAP，且未观察到可信审计、重载核验、交付状态以及原生 HTML/PDF。
  • 未观察到表示本次运行未找到，不外推为软件永远不支持。
