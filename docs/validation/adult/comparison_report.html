3. 对比结果

  • TabularX：将测试隔离、可信审计、模型重载核验和交付状态纳入同一次运行。
  • MLJAR：Explain 模式提供逐模型说明、学习曲线、混淆矩阵和特征重要性。
  • TabularX 最佳模型：lightgbm；MLJAR 最佳模型：Ensemble。

TabularX：21.6 秒；MLJAR：94.7 秒；随机种子 42。
