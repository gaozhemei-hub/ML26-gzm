3. 对比结果

  • TabularX：将测试隔离、可信审计、模型重载核验和交付状态纳入同一次运行。
  • MLJAR：Explain 模式提供逐模型说明、学习曲线、混淆矩阵和特征重要性。
  • TabularX 最佳模型：xgboost；MLJAR 最佳模型：ModelFramework。

4. 运行信息

TabularX：12.9 秒；MLJAR：12.6 秒；随机种子 42。

“未观测”只表示本次固定配置的运行目录中没有找到相应工件，不外推为软件在任何条件下均不支持。
