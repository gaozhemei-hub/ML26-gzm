先选模，再测试：测试集使用流程修复

训练集调参 → 验证集选模 → 保存锁定记录 → 最终拟合 → 锁定模型测试与解释

候选搜索与 Voting 比较不再接收测试数据。未被选择的模型不生成测试分数或测试诊断图；报告不会将“未测试”填成零。

两组真实实验

每组比较随机森林与 XGBoost；各运行一次小规模调参，8 棵树，最大深度 3。这些实验检查流程正确性，不比较工具性能。

与两个创新点的关系

选模锁定记录现在进入证据交付清单；报告或解释失败后仍可局部补做，不重新选模或训练。

研究边界

这是主训练、选模和报告路径的修复，不是完整的数据泄露审计。数据概况与类型识别仍会读取全量输入；解释、诊断和重载核对仍会在锁定之后使用测试输入，不声称物理上只调用一次预测。不合并队友的 TrustGuard，也未推送远程。
