# 流水线编排

> 待 Preprocess、ModelSearch 等阶段完成后补充。

## 当前状态

目前 TabularX 实现了管道的前两个阶段：

```
build_profile（观测） → split_data（划分） → （待实现）
```

## 未来设计方向

流水线编排层（可能存在 `tabularx.pipeline` 中）负责组装各纯函数阶段，并管理 IO：

1. **读取数据** → 2. **Profile** → 3. **Split** → 4. **Preprocess** → 5. **Model Search** → 6. **输出报告**

编排层不写业务逻辑，只做：
- 按顺序调用各阶段函数
- 在每阶段之间传递 schema 对象
- 调用 reports 模块生成 HTML
- 将产物写到磁盘

各阶段的业务逻辑仍然保持在 `core/` 的纯函数中，编排层不关心"怎么判断是否需要 scale"这类问题。
