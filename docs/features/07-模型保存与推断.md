# 07｜模型保存与推断

TabularX 为每次运行保存模型工件，并提供适用于原始表格输入的端到端推断流水线。

## 两类模型文件

- `pipeline.joblib`：包含拟合后的预处理器和模型，推荐用于推断；输入应为与训练列结构兼容的原始 DataFrame。
- `best_model.joblib`：底层模型对象，不包含原始输入预处理；输入应为已按训练流程变换的特征矩阵。

示例：

```python
import joblib

pipeline = joblib.load(ae.output_dir / "pipeline.joblib")
predictions = pipeline.predict(raw_new_df)
```

只加载可信来源的 joblib 文件。跨环境使用还需满足依赖和模型库兼容要求。

## 重载核对

运行交付流程会核对保存流水线重载后的预测与内存模型的结果，并记录核对状态。它用于发现当前兼容环境中的序列化或推断不一致，不证明跨操作系统、依赖版本和硬件完全复现。

模型文件位置和结果对象见 [API 参考：模型持久化与推断流水线](../api_reference.md#62-模型持久化与推断流水线)。
