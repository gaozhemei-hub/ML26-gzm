# 00｜功能总览

本文档目录只介绍 `TabularX-project/src/tabularx/` 中 TabularX 主包向用户提供的功能。课程材料、论文内容、旧版 TrustGuard、测试脚本、基准实验和开发过程记录不属于本目录的功能范围。

TabularX 面向表格数据的分类与回归任务，通过 `AutoEstimator` 将数据画像、划分、预处理、模型搜索、解释评估和结果保存组织为一次建模运行。

## 建模流程

```text
原始表格 X、目标 y
  → 数据画像与静态风险预检
  → 训练/验证/测试划分与完整性审计
  → 预处理与分布/群体覆盖审计
  → 候选模型搜索、验证集选模与最终测试
  → SHAP 解释与可选公平性评估
  → 报告、模型和结构化证据交付
  → 加载流水线进行推断
```

## 功能说明

- [01｜数据画像与静态预检](01-数据画像.md)：数据概况、列类型、目标变量和潜在泄露风险检查。
- [02｜数据划分与完整性审计](02-数据划分.md)：随机、分层、分组、时间划分及跨集合完整性检查。
- [03｜数据预处理与漂移审计](03-数据预处理.md)：缺失值处理、缩放、类别编码、训练集拟合和分布/群体覆盖检查。
- [04｜模型搜索与评估](04-模型搜索与评估.md)：候选算法、超参数搜索、验证集选模和测试集评估协议。
- [05｜解释与公平性评估](05-解释与公平性评估.md)：SHAP 工件、敏感群体评估及其适用边界。
- [06｜报告与证据交付](06-报告与证据交付.md)：报告、工件状态检查、失败原因记录和同会话局部补做。
- [07｜模型保存与推断](07-模型保存与推断.md)：流水线和底层模型文件、重载核对及预测方法。
