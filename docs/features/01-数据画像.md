# 01｜数据画像与静态预检

数据画像是 `AutoEstimator.fit(X, y)` 的第一阶段。TabularX 汇总输入表格的行列规模、列类型、缺失和统计特征，并识别目标变量的任务类型，为后续划分和预处理提供画像信息。

## 静态风险预检

画像阶段可检查可能的高唯一性标识符、特征与目标直接复制、疑似目标代理，以及用户声明为预测时不可获得的字段。用户可在 `ae.param.profile` 中配置 `id_columns`、`forbidden_features` 和相关阈值。

预检主要产生风险发现和建议，不会仅凭统计线索自动推断全部业务语义。是否将建议字段排除出模型，需结合预处理阶段的审计排除配置。

## 结果与报告

画像结果位于 `ae.result.profile`，包含数据规模、列事实、目标信息和画像审计结果。阶段报告路径可从 `ae.result.report_paths` 查询；完整对象字段请参阅 [API 参考：结果契约](../api_reference.md#4-结果契约与中间对象-result-schemas)。

## 边界

- 自动类型和风险判定是基于输入数据的启发式分析，应由用户结合字段含义核实。
- 用户应明确声明 ID 或预测时不可获得的字段；工具无法替代领域知识。
- 画像结果是后续处理依据，不等于数据质量认证或无泄露保证。
