# 03｜数据预处理与漂移审计

预处理阶段按画像和配置处理输入列，产出可供模型使用的特征矩阵。缺失值填充、数值缩放、偏斜变换、类别编码，以及文本和日期列的处理方式均可通过 `ae.param.preprocess` 配置。

预处理器只在训练数据上拟合，再应用于验证集和测试集，以避免把留出集统计量用于拟合变换。拟合后的预处理状态也会用于之后保存的推断流水线。

## 审计相关处理

- 可选择是否将声明的分组列排除出模型输入。
- 可配置是否应用画像阶段提出的字段排除建议；默认策略是仅报告建议。
- 可比较训练、验证和测试集合间的数值/类别分布，并检查敏感群体覆盖情况。

分布差异是风险线索，不直接证明数据泄露或模型失效。群体覆盖审计与模型公平性指标是不同检查。

## 配置和结果

常用配置包括 `numeric_impute`、`categorical_impute`、`scale_method`、`skew_method`、类别编码策略、`apply_audit_drops` 和 `enable_drift_audit`。处理结果位于 `ae.result.preprocessed`，其中包括各数据子集的变换结果、拟合后的预处理器和审计记录。参数细节见 [API 参考：PreprocessConfig](../api_reference.md#33-preprocessconfig)。

## 边界

- 文本、日期和高基数类别的处理受配置和当前实现能力限制；请以 API 和错误提示为准。
- 自动排除字段默认不执行；启用前应检查字段业务含义和审计建议。
- 漂移指标受样本量、分箱和数据类型影响，不能单独作为上线决策依据。
