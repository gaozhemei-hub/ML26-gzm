# 02｜数据划分与完整性审计

TabularX 将输入样本划分为训练集、验证集和测试集。训练集用于拟合预处理器和候选模型；验证集用于比较候选模型；测试集用于最终锁定模型的评估。

## 划分策略

通过 `ae.param.split` 配置划分比例、随机种子和策略。支持自动选择、分层、随机、分组和时间切分。存在实体或时间结构时，可声明 `group_column` 或 `time_column`，并选择适合的策略。

## 完整性检查

划分后可检查跨集合重复样本、实体跨集合重叠和时间边界异常。结果保存在 `ae.result.split.audit`，划分索引保存在 `ae.result.split`。

没有声明实体或时间字段时，对应检查可能显示未执行；这不等同于检查通过。检查结果和建议应结合数据生成机制解释。

## 配置和结果

常用配置包括 `test_size`、`validation_size`、`random_state`、`split_strategy`、`group_column`、`time_column` 和 `enable_split_audit`。详情见 [API 参考：SplitConfig](../api_reference.md#32-splitconfig)。

## 边界

- 划分策略是否符合业务部署场景取决于用户对实体、时间和采样过程的声明。
- 检测上限或抽样策略可能影响大数据集上的重复检查范围；结果会注明相应检查状态。
- 划分审计发现风险或未执行项，不代表工具可以自动修复所有数据问题。
