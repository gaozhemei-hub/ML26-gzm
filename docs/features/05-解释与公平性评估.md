# 05｜解释与公平性评估

模型搜索完成后，TabularX 可对锁定模型生成 SHAP 解释，并可在用户提供敏感字段时进行子群体公平性评估。相关结果会进入结果对象、报告和适用的结构化证据。

## SHAP 解释

`ae.result.shap` 提供解释统计与图表路径。`ae.param.shap` 可配置解释样本上限、背景样本数量和重点特征数。解释依赖当前模型、数据和可选依赖环境；生成失败会在运行结果和交付记录中体现。

## 公平性评估

用户可通过 `fit(X, y, sensitive_features=[...])` 或对应配置指定原始表格中的敏感字段。结果用于比较适用群体的预测和性能差异。当前 DP/EO 指标存在任务与标签形式限制；不满足条件时应查看“不适用”或无法计算的记录。

## 解释边界

- SHAP 描述模型输出与特征之间的归因关系，不自动证明因果关系或解释忠实性。
- 公平性评估依赖敏感字段、分组方式、标签和样本量；指标结果不构成公平性保证。
- 评估与审计不等于偏差缓解；本功能不承诺自动消除偏差。
- 测试集上的解释和诊断会使用测试输入，因此测试集不应被表述为全流程只读取一次。

详细结果结构见 [API 参考：ShapResult / FairnessResult](../api_reference.md#46-shapresult--fairnessresult)。
